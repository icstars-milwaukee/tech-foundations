# Responsible AI Use Checklist

**Name:** Jose and Fernando

Run through this list **every time** you use AI output for something that matters: code you'll commit, writing someone else will read, a decision, a demo.

## Before you prompt

- [ ] I'm using an approved AI tool.
- [ ] I removed personal data: names tied to private details, emails, phone numbers, addresses, IDs, health info, passwords, API keys.
- [ ] I removed company or client data I don't have permission to share.
- [ ] My prompt says what to do when the AI doesn't know ("write UNKNOWN, don't guess").

## After you get output

- [ ] I read the **whole** output, not just the first lines.
- [ ] Every fact, number, name, and date is checked against a real source.
- [ ] Every link, citation, or library name actually exists. I opened it.
- [ ] Code runs, and I can explain what each part does.
- [ ] I asked: could this treat any group of people unfairly or leave someone out?
- [ ] I decided: **accept**, **edit**, or **reject**.

## When you share it

- [ ] I'd be comfortable explaining every line to my trainer or a client.
- [ ] I said AI helped when that matters (school work, client work, anything someone will rely on).

## Our additions

Add **at least two** items from today's case studies. Make each one something you can actually check off. "Be careful" isn't checkable. "Every statistic has a source I opened" is.

- [ ] Ask AI to cite its sources so you can validate the output.
