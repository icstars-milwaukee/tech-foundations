### What each step means

| Step | Write down |
|---|---|
| Reproduce | The exact command you ran and what you saw. Can you make it happen every time? |
| Inspect logs | The error message, the file, and the line number. Read the *first* line of the error. |
| Add logs | Where you added `log.debug(...)` and what the values were. |
| Hypothesize | "I think ___ is happening because ___." One guess at a time. |
| Fix | What you changed, and the line you marked `// FIX:`. |
| Verify | How you proved it works (`npm test` passing, the right number on screen). |
| Commit | The exact message: `fix: root cause ...` |
