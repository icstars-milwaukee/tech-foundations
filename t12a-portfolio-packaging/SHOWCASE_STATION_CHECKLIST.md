# Showcase Station Checklist

**Name:** 
**Project at my station:** 

For the **Employer Showcase**. Go through it the day before **and** again 30 minutes before doors open.

## The laptop

- [ ] Charged, charger plugged in at the table
- [ ] Notifications off (Focus / Do Not Disturb), personal tabs and apps closed
- [ ] Screen brightness up, text zoomed so someone standing can read it
- [ ] Logged in to everything the demo needs. Passwords not saved on screen.

## The demo

- [ ] Quality gate green (T11A `npm run gate` or your own checklist)
- [ ] Test data seeded: made-up data, nothing private
- [ ] Offline fallback ready in case the venue wifi fails
- [ ] Demo starts from one bookmark or one command
- [ ] A 30-second version and a 2-minute version, both rehearsed

## The repo

- [ ] Portfolio repo public, README finished, tagged release
- [ ] Quickstart validated by a peer (`QUICKSTART_VALIDATION.md`)
- [ ] QR code or short link to the repo printed at the station

## You

- [ ] 60-second pitch rehearsed out loud at least 3 times
- [ ] Two questions you'll ask employers
- [ ] Recovery line ready if the demo breaks (from your T11B pressure plan)
